# Outreach Pitches & Messaging — First 10 Merchants

This document contains ready-to-use outreach templates for acquiring the first
10 merchants to the **New One Two (Ton)** platform. All templates are written
to be personalized before sending — replace `{{placeholders}}` with
merchant-specific details.

---

## Core Positioning

**One-line pitch:**
> Ton turns plain-English descriptions into full-stack Shopify apps — storefront widgets, backend logic, and admin UI — deployed to your store in minutes.

**Three value props (pick one per channel):**
1. **Cost:** Replace 3-5 paid Shopify apps with one platform.
2. **Speed:** From idea to live store feature in under 5 minutes.
3. **Flexibility:** Unlimited revisions — describe changes in English, get them live.

**Hero use cases** (lead with ONE, not all):
- Abandoned cart recovery emails
- Back-in-stock alerts
- Order thank-you emails
- Custom wishlist / favorites
- Spin-to-win popup

## Pitch Mechanics — Best Practices

### What to ALWAYS include
- **Specific offer:** "Free Pro tier for 3 months" or "I'll build your first app personally"
- **Low commitment:** "15-minute call" or "5-minute install"
- **Social proof (when you have it):** "Other merchants like {{X}} are already using it"
- **Clear next step:** One single call-to-action

### What to NEVER include
- Long feature lists (you have 34 app types — pitch ONE)
- Technical jargon (no mentions of harness, Pub/Sub, Cloud Run)
- Vague promises ("transform your business")
- Multiple CTAs in one message
- Pricing before value (save pricing discussion for the demo call)

### Personalization checklist (do this before every send)
- [ ] Use their first name
- [ ] Reference their store name
- [ ] Mention ONE specific thing about their store/content (proves you looked)
- [ ] Suggest ONE specific app that would help them
- [ ] End with a single yes/no question

## Objection Handling

### "I already use {{competitor_app}}"
> Totally fair — most of our beta merchants were already paying for 2-3 apps. Ton doesn't replace everything, but it lets you consolidate the $10-30/month ones into custom versions. Want me to rebuild your {{competitor_app}} functionality for free so you can compare side-by-side?

### "Is the generated code reliable?"
> Great question. Every app goes through an automated validation loop — the AI writes the code, tests it, and revises until it passes. Plus you get unlimited human-in-the-loop revisions. If something's broken, you describe the fix in plain English and Ton ships a new version.

### "What if I need changes later?"
> That's the best part — revisions are unlimited and work the same as generation. "Make the email button green and add a coupon code" → 2 minutes later it's live. No developer needed.

### "How much does it cost?"
> Early access is free for the first 10 merchants (3 months of Pro tier). After that, plans start at $[Free/Starter price] and scale based on how many apps you run. For stores currently paying $80-150/month across multiple apps, Ton usually cuts that in half or more.

### "What happens to my apps if Ton shuts down?"
> Legitimate concern for any SaaS. We're building with portability in mind — the generated code is standard TypeScript and SQL, and you own it. In a shutdown scenario we'd provide an export of your app bundles. (Note: we're not planning to shut down — just answering honestly.)

### "I'm not technical — is this for me?"
> Ton is specifically built for non-technical merchants. You never see code. You just describe what you want in English, and Ton handles everything. If you can write a sentence, you can use Ton.
